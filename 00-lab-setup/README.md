# DevOps Cloud Lab - Workstation Setup

## Environment

- Host OS: Windows 11 Pro
- Linux Environment: WSL2
- Linux Distribution: Ubuntu 22.04 LTS
- Container Platform: Docker Desktop
- Source Control: Git and GitHub
- Cloud Platform: Microsoft Azure

## Lab Purpose

This lab is being built to develop hands-on skills in DevOps, Cloud Engineering and Site Reliability Engineering.

The environment will gradually include Linux, Docker, Ansible, Terraform, Azure, Kubernetes, CI/CD, monitoring and troubleshooting exercises.
